# Guía de Contribución

Gracias por tu interés en contribuir a este proyecto.

## Cómo proponer un cambio

- Haz un fork del repositorio.
- Crea una rama con un nombre descriptivo.
- Envía un Pull Request explicando *qué* cambiaste y *por qué*.

## Normas de estilo

- Los mensajes de commit deben ser claros y en español.
- No se aceptan cambios sin descripción en el Pull Request.
