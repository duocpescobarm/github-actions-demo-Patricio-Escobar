# Código de Conducta

## Nuestro compromiso

Nos comprometemos a mantener un ambiente de colaboración ~~hostil~~ **respetuoso**
para todas las personas que participen en este proyecto.

## Comportamiento esperado

- Usar un lenguaje inclusivo y respetuoso.
- Aceptar críticas constructivas.
- Enfocarse en lo mejor para la comunidad del proyecto.
